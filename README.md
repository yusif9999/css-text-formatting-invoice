# Corporate Digital Invoice Summary

A clean, professional, and responsive-friendly digital invoice summary template built exclusively with HTML and core CSS. 

This project was developed as a focused practice on CSS fundamentals, specifically isolating **CSS Typography** and the **Box Model** without relying on modern layout modules like Flexbox or CSS Grid.

## 🎯 Project Focus & Concepts Applied

The primary goal of this repository is to master text formatting and structural spacing in CSS. The following core CSS properties were heavily utilized and practiced:

*   **Typography & Text Formatting:**
    *   `color` - Applying corporate color schemes.
    *   `text-align` - Structuring table data and headers.
    *   `text-decoration` - Managing link styles and emphasizing due dates.
    *   `text-transform` - Standardizing document headers (uppercase).
    *   `text-indent` - Formatting legal contract paragraphs professionally.
    *   `letter-spacing` - Enhancing the readability of main titles.
    *   `word-spacing` - Highlighting critical warning texts (e.g., late fees).
*   **Box Model Fundamentals:**
    *   Extensive use of `margin`, `padding`, and `border` to create a structured document flow.
    *   Implementation of `outline` for the "UNPAID" status stamp.
    *   Using `max-width` and `margin: 0 auto;` for document centering.
*   **Inheritance:**
    *   Utilizing `inherit` to maintain color consistency across specific nested elements.
